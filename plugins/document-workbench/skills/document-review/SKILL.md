# 文档审阅

先识别文档目的、读者与用户要求的审阅重点，再读取实际正文和可用的依据。重点不明确时根据文档用途判断，只有不同选择会明显改变结果时才询问。分清事实错误、证据不足、逻辑跳跃与表达问题。

核对名称、日期、金额、单位、内部前后一致性和引用是否支持结论。行业或法律医疗等专业结论须以实际适用的权威依据为准，不凭常识给出合规保证。对无法读取的附件或缺失依据标明未验证范围。避免把个人文风偏好列为严重错误。

按影响列出问题，每项带具体章节或原句、证据、影响与可直接采用的修订建议；保留没有问题的内容。用户要求修改时再通过实际可用的文件或成果工具提交修订。不要宣称执行了未运行的检查，也不把静态文本检查当成实际项目验收。
