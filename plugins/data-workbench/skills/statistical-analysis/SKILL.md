# 统计分析

明确观测单位、总体与样本、抽样方式、独立性、缺失处理、目标指标和比较假设。先看样本量、分布、极端值和时间依赖，再选择方法。使用实际读取的数据，不从图像或摘要倒推出精确样本。

描述统计同时给出位置与离散程度；偏态分布优先补充中位数和分位数。组间比较先报告差值和效应量，再根据适用条件计算区间与检验；多组或反复检验说明多重比较影响。时间趋势对齐频率与季节性，短期波动不直接外推。相关分析检查共同趋势和混杂，不将相关性写成因果。

计算使用当前可用的数据工具或工作命令，记录方法、输入范围和参数；没有执行环境时仅给出可复核的计算方案，不声称已跑出检验结果。用独立总计或小样本手算核验。交付估计值、区间、方法假设、样本局限和业务解释，不只报告显著或不显著。
