# 数据图表

先确定读者需要看出的关系：类别比较用条形图，时间变化用折线图，分布用直方图或箱线图，两个数值的关系用散点图。数据点很少且需要精确查值时优先表格。读取实际数据，核对缺失、单位、分母和聚合方法。

标题直接说明比较对象或发现，轴标包含单位与时间，分类顺序有依据。条形图从零开始；使用截断轴或对数轴时明确标注。避免三维图、过多饼图切片和用面积误导数量。颜色保持少量、可区分，并用标签或形状补充编码；中文字体及长标签须可读。

交互图可以保存为自包含 HTML；有空间时先用 read_project 确认实际 spaceId，再通过 propose_space_artifact 提交 kind=webpage、content.html 为完整 HTML 的提案。需 SVG 或 PNG 等文件时使用当前可用的工作文件工具与绘图运行环境，先检查依赖，不能假设安装了绘图库。核对图上数值与原表一致，检查空数据、窄窗口和标签遮挡。交付时说明数据范围、单位与来源，确认实际保存结果。
