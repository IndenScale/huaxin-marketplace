# 数据探索

确认数据来源、记录粒度、字段含义、主键和预期规模，实际读取表头及样本，不仅凭文件名推测字段。先用 read_project 定位可用附件与文件工具。对于工作文件夹中的 CSV，可用 run_skill_script 运行本技能 scripts/profile.mjs，参数为实际 CSV 文件的绝对路径；该脚本只读文件并输出 JSON 概览。没有工作文件夹或脚本执行条件时，使用当前实际可用的阅读或数据连接工具。

区分空值、零值、无效文本和未知值。检查重复记录、字段类型混用、日期跨度、数值范围、异常单位、分类基数与长尾。大数据先抽样，再说明覆盖范围；不能把样本统计当作全量结果。识别适合连接的键，但在核对一对多关系之前不做合并。

交付字段字典、质量问题及其位置、会影响哪些分析、建议修订动作和后续可研究的问题。脚本不理解业务口径，其数值识别只用于初筛；结合原始字段和用户定义判断。保留原始文件，不自动去重或补值。
