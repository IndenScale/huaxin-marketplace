# 交互看板

明确看板读者、关注的决策、指标口径、时间与分类筛选。通过 read_project 读取实际资料与目标空间，读取已有成果后再编辑，不能猜测成果编号或版本。先核对数据粒度、单位、总计与分母。

使用完整自包含 HTML，在同一文件内包含样式、脚本和经过必要转义的数据。优先原生 SVG、HTML 表格和浏览器交互，避免依赖外部 CDN 或把用户数据发到第三方。以最少的核心指标、关键趋势、分类比较和明细组织页面，筛选后所有相关视图必须同步，并处理空结果、重置、键盘操作与窄窗口。静态快照显示实际数据日期，不能暗示持续实时更新。

有目标空间时，通过 propose_space_artifact 提交 kind=webpage、content={html:完整HTML}，更新时附实际 id 与 revision。需要普通文件时用当前任务允许的工作文件提案或命令保存。用浏览器预览核对筛选前后总计、空状态和布局，条件不足时如实标明未验证的交互。保存前属于提案，保存成功后再交付文件或成果入口。
