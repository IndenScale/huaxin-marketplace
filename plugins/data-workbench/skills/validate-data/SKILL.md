# 分析结果校核

读取待检查成果及其实际输入数据，明确用户要验证的范围。先列出主要结论与支撑它们的指标，沿来源、处理、计算、图表、叙述逐项追溯。只看到最终报告时，区分可核对的算术与缺少原始输入的判断。

重点复核连接重复、筛选范围、时间窗口、分母变化、加权与非加权平均、百分比与百分点、累计与当期、四舍五入以及币种单位。用第二种聚合方式或小样本独立重算，不能仅重复原公式。核对图表轴、排序、标签、表格总计和正文数字，检查结论是否超出样本与方法。

交付按影响排序的问题清单，每项包含位置、证据、影响和具体修订动作。明确哪些检查已完成、哪些因缺少输入未验证；无需制造错误凑数量。用户要求修订时保留原始数据并以实际版本提交成果更新。
