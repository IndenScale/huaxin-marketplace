# 数据分析

先确定用户要据此做什么决定，明确指标定义、时间区间、比较基准、样本范围和单位；已有上下文足够就直接分析。通过 read_project 找到附件、资料和已连接工具。用 read_document 或可用的数据连接工具读取实际数据；工作文件通过当前任务的文件工具读取。

按问题复杂度选择单一指标核对、分组比较、趋势拆解或完整报告。先检查重复行、缺失值、口径变化、分母与连接键，再计算聚合；占比同时提供分子分母，平均值说明权重，跨期比较对齐时间窗口。区分观察到的变化、可能解释与尚未验证的因果关系。抽取小样本与总计交叉核对，保留计算过程。

交付包括直接回答、支持结论的数值或图表、数据范围与局限，以及可执行的下一步。使用实际来源与时间，不填补未知数字。需要保存时，用已有空间的 propose_space_artifact 提交表格或网页提案；用户要求工作文件时使用任务允许的文件提案或命令工具保存并读取核对。只有保存或导出成功才报告文件已生成。
