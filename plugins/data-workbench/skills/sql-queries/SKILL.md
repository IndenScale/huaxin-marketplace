# SQL 查询

先取得数据库方言、实际表与字段结构、记录粒度、时间字段、连接键以及目标指标。使用当前已连接的数据工具读取结构，或采用用户提供的 DDL；缺少字段时询问或明确占位，不编造真实字段。

使用清晰的 CTE 分离取数、清洗、聚合与展示。核对一对多连接是否导致重复计量，聚合前确定主键与去重规则；处理时区、日期边界、空值和除零。参数使用数据库支持的绑定方式，不直接拼接用户文本。为查询限定必要的列、分区和范围。

执行须使用实际可用且已授权的数据库工具。先 EXPLAIN 或小范围只读查询，再核对行数、键唯一性和总计；没有执行条件时交付 SQL 与验证步骤，明确未执行。修改业务数据、DDL 与批量删除只在用户明确要求且确认目标范围时处理。交付查询、方言、口径说明、预期字段与性能注意点，不把语法检查当成业务正确性。
