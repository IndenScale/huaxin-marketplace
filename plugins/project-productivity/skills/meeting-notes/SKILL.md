# 会议纪要

读取用户提供的记录或实际可访问的转写，确认会议主题、日期和参与者。记录不完整时保留缺口，不猜测未出现的发言。区分背景讨论、提出的建议、正式决定和未决问题。

行动项包含具体动作、负责人、截止时间和依赖。未明确负责人或期限时写待确认；相对日期只有会议日期明确时才换算为绝对日期。存在互相冲突的说法时保留待核实点，不自行裁决。引用敏感内容仅保留完成纪要所需范围。

交付可独立阅读的纪要和可执行清单。只有用户要求发送或同步任务时才使用对应服务工具，核对实际目标和写入回执；整理出行动项不等于已创建外部任务。
