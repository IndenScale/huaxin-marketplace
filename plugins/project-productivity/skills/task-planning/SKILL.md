# 任务规划

确认目标成果、截止时间、可用人员与资源、已有进展和硬性约束。已有信息足够时直接提出计划；缺少会决定可行性的条件时只问关键问题。先定义可检验的完成标准，再安排工作。

按交付物拆分任务，注明前置依赖、责任、估计工作量和验收方式。把确定日期与估计日期区分，安排必要的验证和反馈时间，不把并行任务机械串联。标出关键路径与影响目标的主要风险，给出出现问题时的调整动作。

交付规模适合当前目标的计划，并明确最先能执行的一步。仅在用户要求同步到现有项目工具时调用实际已连接的服务；没有创建回执时不要声称任务已建立。后续更新计划先读取实际状态，保留完成记录与仍有效的依赖。
