# 华信官方插件市场

为华信 Agent 提供公开插件目录及可安装的技能文件。当前发布三个插件，共十三项技能。

| 插件 | 内容 | 版本 |
| --- | --- | --- |
| 数据分析 | 数据分析、探索、统计、图表、看板、SQL 与分析校核 | 1.0.0 |
| 文档与研究 | 协作文档、研究综合、文档审阅与需求分析 | 1.0.0 |
| 项目协作 | 会议纪要与任务规划 | 1.0.0 |

在华信 Agent 中打开“自定义 → 插件 → 添加 → 添加插件市场 → 从仓库添加”，输入 IndenScale/huaxin-marketplace 并同步。进入发现列表，查看插件版本和组件，确认后安装。后续通过“管理目录来源”同步目录，再确认更新。

这些技能来自华信 Agent 主线随附内容，使用 MIT 许可。数据探索插件含一个只读 CSV 概览脚本，其余内容为技能指令。任务使用华信 Agent 实际提供的文件、资料和工作空间工具；外部服务及模型连接由用户配置。当前发行包含以上三组技能，不包含内置工程工具或 Mac 操作录制工具。

维护使用 Bun 和 Node.js 22.13 或更高版本。运行 bun run check 检查目录、组件、技能标识和随附脚本。修改通过 Pull Request 提交，核对文件差异、实际功能和许可后合并；正式更新递增插件版本，并同时更新目录中的版本。发布标签由维护者明确创建。
