# 华信官方插件市场

为华信小工提供独立的 Marketplace 插件目录。目录包含十个插件、二十项技能；其中七个场景插件版本为 0.1.0，由用户从 Marketplace 按需安装。七个场景插件不随应用预装，应用启动、安装或升级不自动安装这些插件。

| 插件 | 内容 | 版本 |
| --- | --- | --- |
| 数据分析 | 数据分析、探索、统计、图表、看板、SQL 与分析校核 | 1.0.0 |
| 文档与研究 | 协作文档、研究综合、文档审阅与需求分析 | 1.0.0 |
| 项目协作 | 会议纪要与任务规划 | 1.0.0 |
| 设计文档一致性核对 | 两类文档指定对象、字段、单位和原文证据核对 | 0.1.0 |
| 技术方案需求覆盖审查 | 需求与方案映射、覆盖缺口和待复核判断 | 0.1.0 |
| 专项政策分析与汇报准备 | 指定专题的事实、分析、建议、日期范围与依据 | 0.1.0 |
| 数据中心交付资料齐套检查 | 一个阶段的资料清单、业务修订和登记状态检查 | 0.1.0 |
| 经营指标分析与预警 | 指定字段的原值、差值、比值和阈值预警 | 0.1.0 |
| 综合台账更新预览 | 按事项主键形成新增、更新、冲突和无需变更预览 | 0.1.0 |
| 慧作业填报准备 | 指定表单的字段映射、类型和约束校验 | 0.1.0 |

在华信小工中打开“自定义 → 插件 → 添加 → 添加插件市场 → 从仓库添加”，输入 IndenScale/huaxin-marketplace 并同步。已添加此 Marketplace 的用户同步目录即可。进入发现列表，查看插件版本、技能和本机代码说明，确认后安装需要的插件。后续同步目录并确认更新。发布是 Marketplace 目录更新，安装由客户端用户单独选择。

三个通用插件使用 MIT 许可，数据探索含一个只读 CSV 概览脚本。七个场景插件各包含一项中文 Skill、空白输入模板和无第三方依赖的 Node.js 执行脚本，使用相同许可。不包含业务样例、业务文件、账号凭据或平台连接器，不采集业务材料用于开发或验收。

七个场景插件由模型完成资料阅读、字段提取和语义判断，由随附脚本执行确定性核对。生成式步骤需要用户配置可用模型；脚本需要任务关联工作文件夹及宿主执行权限。华信小工的脚本执行接口当前在 macOS 等非 Windows 环境提供；Windows 客户端内的脚本工作流未验收，不能据此保证等效运行。

输入为 UTF-8 JSON，包含明确范围、场景标识、是否合成测试数据和带版本原文。证据使用来源标识、业务位置、UTF-16 字符起点及逐字引文。字段和来源缺失时报告诊断，不补造事实。空白模板不能直接作为有效任务输入。脚本仅读取输入并输出 JSON、Markdown 或可搜索 HTML，不修改原件、不联网、不持久保存业务记录。报告保存通过宿主已授权文件工具完成。

G1 检查字段一致性，不代替专业设计审核；G2 验证覆盖映射，不代替技术正确性判断；G3 核对所填依据和日期，不认定政策效力；G4 核对清单，不签发验收结论；G5 使用已确认公式与阈值，不推断业务原因；G6 生成更新建议，不写入正式台账；G7 准备字段，不连接、保存或提交慧作业平台。

开发使用 Bun，运行脚本使用 Node.js 22.13 或更高版本：

```sh
bun run build:workshop
bun run check
bun run test
bun run package:workshop
```

build:workshop 更新场景插件的技能说明、空白模板和共享运行代码副本；check 检查目录及生成内容同步；test 使用抽象字段与合成数值验证程序规则；package:workshop 生成当前版本的七个独立插件归档、文件大小和 SHA-256 清单。归档供 Marketplace 发行和验包，不触发客户端安装。开发验收不得使用业务样例，也不得自动向用户配置安装插件或发送模型任务。

修改通过 Pull Request 提交，核对文件差异、功能、许可及 CI 后合并到 main，使 Marketplace 当前目录可见。已发布插件更新递增插件版本，并同步目录版本。仓库标签标识固定发行，不替代客户端实际安装证据。专业业务质量、真实模型完成任务和外部系统接入均需另行验证；抽象程序测试不代表业务验收通过。
