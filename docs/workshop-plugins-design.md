# 场景插件规格

日期：2026年10月28日。目标宿主：华信小工。发行位置：IndenScale/huaxin-marketplace 官方 Marketplace。七个插件均为独立 0.1.0 能力包，通过市场发现、用户确认后安装，不进入应用随附目录，不预装，不修改当前用户插件配置。

## 能力与边界

| 标识 | 插件 | 首版目标 | 正式业务动作边界 |
| --- | --- | --- | --- |
| G1 | design-consistency | 两类文档按对象键核对指定字段、缺项和单位 | 不修改设计文件，不签发专业审核结论 |
| G2 | solution-coverage | 核对需求、方案原文及覆盖判断映射 | 不认定技术方案正确，不自动审批 |
| G3 | policy-briefing | 整理事实、分析、建议及政策日期范围 | 不认定政策效力，不发布汇报 |
| G4 | delivery-readiness | 检查一个交付阶段的清单、修订和登记状态 | 不替代技术验收、签章和正式交付 |
| G5 | operating-alerts | 计算已定义原值、差值、比值和阈值预警 | 不持续监控，不自动推断异常原因 |
| G6 | ledger-updates | 按事项键生成新增、更新及冲突预览 | 不清空旧值，不删除记录，不写正式台账 |
| G7 | hui-form-preparation | 检查表单必填、类型、枚举、范围及日期 | 不连接慧作业，不保存或提交表单 |

每个插件包含一项 Skill、中文界面元数据、空白 JSON 输入模板、确定性脚本及 MIT 许可。插件中的语义阅读与判断由可用模型执行；字段核对、计算、日期、引用及输入约束由程序执行。模型配置与宿主脚本审批沿用已有机制，不增加自动安装、后台执行或外部授权。

输入携带场景、范围、合成测试标识和原始来源；来源保留名称、版本与全文。每项证据包含来源标识、业务位置、零起始 UTF-16 字符位置和逐字引文。输出固定输入与来源指纹，诊断携带规则 ID、位置、证据和修订动作。来源核对仅证明引文与所填原文一致，不证明材料本身经过专业审核。

所有脚本只读取单个不超过 4 MB 的 JSON 输入，向标准输出返回 JSON、Markdown 或 HTML。无网络调用、任意表达式求值、业务数据库写入及外部平台提交。结果文件通过宿主授权文件工具保存。公共代码在维护时保持单一来源，构建后随每个插件独立携带，安装包不依赖其他插件文件。

## 结果页

HTML 是本机可搜索结果页，不注册小工一级导航或专业业务模块。以字段对照、指标、变更和诊断表格为核心，支持全文筛选、键盘聚焦及窄屏表格滚动；完整 JSON 保留在可展开区域。源内容作为文字转义，页面不连接外部资源。

视觉采用工程资料检查表的层级：页面底色 #F3F6FA、内容底色 #FFFFFF、正文 #203247、分隔线 #D5DFE9、次级文字 #52657A、强调色 #175D9B。中文使用系统苹方或微软雅黑；标题28px、分区18px、正文15px、表头13px。标题与范围左对齐，搜索在表格上方，诊断位于结果之后。深色随系统切换，避免无业务含义的装饰和状态宣称。

## 验证要求

开发及验收不使用业务样例，不构造业务案例。自动检查仅使用内存中的抽象标识、字段和合成数值。覆盖输入保持只读、可重复执行、证据偏移、重复主键、缺项、冲突、单位、零分母、日期与字段约束、报告转义和 CLI 真实输出。

宿主兼容验证使用隔离临时配置，验证包解析、安装、加载、脚本审批后执行、启停、重开及移除，完成后清理。发布验证从真实远程 Marketplace 固定提交读取目录与各插件、校验组件和脚本，不安装到当前用户配置。未实际完成的界面、模型任务、Windows 原生工作流及外部平台接入不得记为验收通过。
