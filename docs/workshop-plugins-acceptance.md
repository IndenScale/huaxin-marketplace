# 场景插件本地技术验收

日期：2026年10月28日。对象：华信官方 Marketplace 新增七个 0.1.0 场景插件。目录共十个插件、二十项技能。开发使用 Bun，脚本实际运行于 Node.js；插件按 Marketplace 独立发行，不随华信小工应用预装。

## 实际通过

目录与组件检查通过：七个插件各包含清单、MIT 许可、中文 Skill、界面元数据、空白输入模板、独立脚本和随附运行代码。目录、插件身份、版本和生成内容一致；没有随附连接器、账号凭据、业务文件或业务样例。

41项自动检查通过。覆盖七组输入只读与重复执行、范围和来源验证、实际 CLI 的 JSON、Markdown、HTML 输出、字段差异与单位、需求映射、日期与依据、交付清单修订和状态、指标公式及阈值、缺失值与零分母、台账冲突及重复处理、表单类型与约束、UTF-16 引文定位、报告转义、失败诊断和 macOS 路径别名调用。

七个独立 ZIP 已生成并重新解析，均为单插件根目录，包含七个实际文件。每包记录版本、字节数、SHA-256 和文件数。归档不包含测试夹具、验收输出或维护脚本。

在隔离临时配置中使用华信小工源码宿主接口逐包验证归档导入、安装、技能加载和资源读取、真实脚本执行、宿主命令批准后执行、停用与恢复、重新打开接口后身份保留及移除。确认这七项不在应用随附插件目录。隔离配置、临时任务和合成输入在检查后清理；未向当前用户配置安装这七项。

使用真实 Chromium 检查七个 HTML 结果页。每页搜索、清空恢复、完整结果展开和键盘聚焦通过；浅色、深色各在390、920、1280像素宽度检查，共42种组合，页面无横向溢出，浏览器脚本错误为零。页面输入仅为抽象字段和合成数值。

## 验收范围

所有输入均为程序内的抽象技术测试，不涉及业务样例、真实业务资料或编造的业务案例。没有发送模型请求，没有配置外部平台账号，也没有创建平台草稿、提交表单或写入正式台账。

上述检查证明确定性脚本、组件机制和结果页在所述环境中可运行，不证明模型阅读、抽取、专业判断及七个业务场景的实际质量。华信小工主线安装应用的界面验收曾在启动阶段超时，未进入安装流程，未计为通过。Windows客户端脚本工作流未验收。远程 Marketplace 发布与公开目录回读属于独立发布验证，不由本记录推定成功。
